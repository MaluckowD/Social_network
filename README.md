# SocialSphere — социальная сеть 👥  

## 🔍 Основные возможности  

### 👤 Профили пользователей  
- Просмотр списка всех пользователей с пагинацией  
- Возможность подписаться/отписаться от других пользователей  
- Базовые профили с основной информацией  

### 🤝 Социальные взаимодействия  
- Система подписок
- Отображение статуса отношений (подписан/не подписан)  

## 🛠 Технологии  
- **Frontend**: React + Redux  

## 📅 Планы развития  
- Лента активности  
- Личные сообщения  
- Система постов и лайков  
- Настройки приватности
